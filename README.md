\## Project Description

This project implements conditional date generation using deep generative models.  

The input is a set of four conditions:



\- Day of week

\- Month

\- Leap-year flag

\- Decade



The output is a generated date that satisfies the given conditions within the range 1-1-1800 to 31-12-2200.



\## Implemented Models

The notebook and model folder include four models:



1\. Conditional VAE

2\. Conditional GAN

3\. LSTM Seq2Seq

4\. Transformer Encoder-Decoder
